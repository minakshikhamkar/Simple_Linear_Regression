# Simple_Linear_Regression # Simple Linear Regression Model

## Project Overview
This project implements a Simple Linear Regression Machine Learning model using Python and Google Colab to predict employee salary based on years of work experience.

## Dataset
Salary Dataset – Years of Experience vs Salary (Kaggle).

## Algorithm Used
Simple Linear Regression (Regression).

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps
1. Import required libraries.
2. Load the Kaggle dataset.
3. Perform data inspection and preprocessing.
4. Visualize the data using graphs.
5. Separate input and output variables.
6. Split the dataset into training and testing data.
7. Train the Simple Linear Regression model.
8. Predict employee salaries.
9. Evaluate model performance using MAE, MSE, RMSE and R² Score.
10. Visualize the regression line.

## Output
The model predicts employee salaries based on years of work experience and evaluates prediction performance.

## Platform
Google Colab
